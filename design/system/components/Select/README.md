# Select
A radio group of small buttons; the chosen item's `value` is sent to the channel.

**Source:** `lib/switch.js` (react-bootstrap `ToggleButtonGroup`, `.selectbtngroup`).

## Definition
`id`, `label`, `items` (`[{name, value}]`), `defval`, `vertical`.

## Usage
- Options: `button-sm` text on `cs-surface-2` with `cs-border`; hover `cs-surface-3`; checked `cs-blue` with `white` text.
- The group has `radius-btn-sm` on its outer corners only.
- `vertical: true` stacks the options (used by the LFO type list).
