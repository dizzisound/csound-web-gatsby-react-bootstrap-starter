# ValueBox
The editable numeric read-out under a fader.

**Source:** `lib/fader.js` (`NumericFormat` with class `valuebox`).

## Usage
- `value` style in `white` with tabular figures on a `cs-bg` well, `cs-border` outline, `radius-input`, `valuebox-padding-x`.
- Focus turns the border `cs-accent`.
- The `unit` option is appended after a space (`0.1 s`); `size` sets the width in characters.
